# 🤖 AI Assistant

> Универсальный CLI-помощник с поддержкой чат-ботов, генерации изображений и локальных моделей.

---

## ✨ Возможности

- **💬 Чат-бот** — общение с LLM в реальном времени с сохранением контекста диалога
- **🎨 Генерация изображений** — создание картинок по текстовому описанию
- **📁 Сохранение чатов** — экспорт и загрузка историй переписки в JSON
- **🧠 Глубокая генерация** — расширенные ответы через продвинутый промпт
- **📖 Чтение из файлов** — загрузка контекста из `.odt` документов
- **🌐 Автоперевод** — автоматический перевод русских промптов на английский для генерации изображений
- **⏱️ Тайминг** — отображение времени генерации ответа
- **🎨 Цветной вывод** — удобная подсветка в терминале
- **🖥️ Локальные модели** — поддержка офлайн-работы через `LocalClient`

## 🚀 Использование

Запустите программу:

```bash
python AI.py
```

### Главное меню

```
Модовая панель:
  → • Чат бот
  • Генерация картинки
  • Вернуться к чату
```

### 💬 Чат-бот

1. Выберите режим генерации:
   - **Глубокая генерация** — подробные ответы с расширенным промптом
   - **Обычная генерация** — стандартные ответы
   - **Читать из файла** — загрузка контекста из документов `.odt`

2. Вводите вопросы — ответы отображаются с таймингом и цветовой подсветкой

3. Введите `.` для сохранения чата:
   - Укажите название файла
   - История сохранится в папку `prompts/` в формате JSON

### 🎨 Генерация изображений

1. Введите описание картинки (промпт)
2. Русские промпты автоматически переводятся на английский
3. Получите ссылку на сгенерированное изображение

### 📖 Загрузка чата

1. Выберите сохранённый чат из папки `prompts/`
2. История загрузится и диалог продолжится

## ⚙️ Настройка

### Выбор модели

В файле `AI.py` измените переменные:

```python
model_ch = "deepseek-r1"       # Модель для чата
model_image = "flux"            # Модель для изображений
```

### Локальные модели

Для использования офлайн-моделей:

1. Раскомментируйте строку в `AI.py`:
   ```python
   client = LocalClient()  # раскомментируйте
   ```

2. Укажите модель из списка `LocalModel.txt` в переменную `model_ch`

3. Рекомендуемые модели:
   - **> 8 ГБ ОЗУ** → `Meta-Llama-3-8B-Instruct`
   - **Меньше 8 ГБ** → `Phi-3-mini-4k-instruct`
   - **Для кода** → `DeepSeek-R1` или `starcoder`

### Глубокая генерация

Промпт для расширенных ответов хранится в `promptPLUS.txt`. Вы можете настроить:
- Структуру ответа
- Уровень детализации
- Количество примеров
- Стиль изложения

## ⚠️ Примечания

- Для офлайн-работы с чувствительной информацией используйте локальные модели
- Эмбеддинг-модели (`all-MiniLM-L6-v2`, `nomic-embed-text`) предназначены только для векторных поисков, а не для генерации ответов
- Убедитесь, что у вас достаточно памяти для выбранной локальной модели
